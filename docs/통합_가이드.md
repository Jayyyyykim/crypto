**이걸 제일 먼저 하는 게 핵심이다.** 4주를 기다리지 않고 오늘 표본을 만든다.


## 3. 스케줄 — 일봉 마감 후 하루 1회

봇의 기존 스케줄러(봉마감 감지 루프)에서 **일봉 마감 직후** 한 번만 돌린다.
종목 × 4TF만큼 `analyze_timeframe`을 부르므로 자주 돌리면 안 되고,
환경은 원래 그 주기로만 바뀌는 값이라 자주 돌 이유도 없다.

```python
def daily_regime_job():
    coins = select_paper_universe(COINS, max_coins=100)

    # ① 환경 판정
    scan = regime_gate.scan_universe(coins, analyze_timeframe)
    turns = regime_gate.detect_turns(scan)
    overlap = regime_gate.find_overlap(scan, turns)
    regime_gate.record_snapshot(scan)          # 내일 전환을 세려면 필요

    for cid in CHAT_IDS:
        send_telegram(regime_gate.get_report(scan, turns, overlap), chat_id=cid)

    # ② 오늘 사건 적재 (환경 라벨을 같이 박는다 — 나중에 환경별로 가르려고)
    setup_ledger.capture(coins, get_ohlcv, timeframe="1d", regime=scan["label"])

    # ③ 밀린 채점 따라잡기 (봇이 며칠 꺼져 있었어도 한 번에 복구된다)
    setup_ledger.score_pending(get_ohlcv, timeframe="1d")
```

## 5. 페이퍼 트레이딩에 게이트 붙이기

`paper_trader.py`의 `capture_signals()`에 게이트 인자를 하나 더한다.
**표본을 늘리는 것보다 '환경 맞을 때만 친 표본'을 모으는 게 훨씬 빨리 답을 준다.**

호출 쪽:

```python
_regime_cache = {"scan": None}

def paper_gate(symbol, direction):
    scan = _regime_cache.get("scan") or regime_gate.load_latest()
    if not scan:
        return True, "환경 미판정 — 게이트 미적용"   # 없으면 막지 않는다
    row = regime_gate.symbol_alignment(symbol, analyze_timeframe)
    return regime_gate.gate(direction, scan, symbol_row=row)


paper_trader.capture_signals(detect_core_signal, coins,
                             get_price_fn=get_current_price,
                             gate_fn=paper_gate)
```

> `load_latest()`는 30시간 지난 스냅샷을 `None`으로 돌려준다 — 어제 환경으로
> 오늘 진입을 허용하면 게이트가 무의미하기 때문이다.

**게이트를 켠 뒤에도 원장은 게이트 없이 계속 모아라.** 그래야
`setup_ledger.compare_regimes()`로 *"게이트가 실제로 성적을 올렸나"* 를
채점할 수 있다. 안 올렸으면 그 게이트는 표본만 줄이는 장치다.

## 6. 손절 sanity check (선택)

시그널을 등록하기 전에 손절이 한 봉 예상 범위 안에 갇혀 있는지 본다.

```python
df = get_ohlcv(symbol, "4h", limit=160)
er = expected_range.expected_range(df, live_price=get_current_price(symbol))
warns = expected_range.check_trade_levels(er, entry, sl, tp1)
if warns:
    print(f"[페이퍼] {symbol} 레벨 경고: {warns}")
```

처음에는 **거르지 말고 로그만 남겨라.** 몇 주 뒤 원장과 대조해서
"경고 뜬 거래가 실제로 더 나빴나"를 확인한 다음 거르면 된다.

## 8. 권장 순서

1. **소급 채점 돌리고 `/채점표` 읽기.** 초과 적중률이 전부 ±2%p 안이면,
   지금 쓰는 셋업 중 시장 방향을 빼고 남는 게 없다는 뜻이다.
   그 상태로 자동매매를 올리면 안 된다.
2. 초과가 유의미하게 나오는 셋업이 있으면 **그것만** `detect_core_signal`에
   반영하고, 환경 게이트를 켠 페이퍼로 검증한다.
3. `compare_regimes()`로 게이트의 값어치를 채점한다.
4. 그 다음에 `자동매매_설계서.md`의 2단계(반자동)로 간다.

설계서의 원칙 그대로다 — **"앞 단계가 숫자로 증명되기 전에 다음 단계로 가지 않는다."**
이번에 더한 건 그 '숫자'를 4주가 아니라 오늘 얻는 방법이다.
